# algrus-core

АлгРус — алгоритмический язык русской нотации. Пакет содержит лексер,
парсер, генератор Python-кода и ядро для Jupyter.

## Установка

```bash
python -m venv venv
source venv/bin/activate
pip install -e .

# регистрация ядра в Jupyter
python install.py
```

После установки перезапустите Jupyter и выберите ядро **«АлгРус»**.

## Использование из Python

```python
from algrus_core import Lexer, Parser, PythonCodeGenerator

source = """
АЛГ Пример
НАЧ
ЦЕЛ а, б, сумма;
а := 2;
б := 3;
сумма := а + б;
ВЫВОД "Сумма: ", сумма;
КОН.
"""

ast = Parser(Lexer(source)).parse()
python_code = PythonCodeGenerator().generate(ast)
print(python_code)
```

## Синтаксис

| Конструкция | Пример |
| --- | --- |
| Программа | `АЛГ Имя НАЧ ... КОН.` |
| Заголовок алгоритма | `АЛГ Имя (ВЕЩ a, b, ЛИТ s) АРГ a, b РЕЗ s НАЧ ... КОН.` |
| Объявление | `ЦЕЛ a, b;` / `НАТ n;` / `ВЕЩ x;` / `ЛОГ flag;` / `СИМВ s;` / `ЛИТ s;` |
| Таблицы | `ЦЕЛ таб A[1:100]` / `ВЕЩ таб B[1:10, 1:10]` |
| Элемент таблицы | `A[i] := 5` / `B[2, 3] := 1.5` |
| Присваивание | `a := 10;` или `a = 10` |
| Степень | `x^2`, `2^3^2` |
| Строки | `"текст"`, `«текст»`, `„текст"` |
| Условие | `ЕСЛИ a > b ТО ... ИНАЧЕ ... ВСЕ;` |
| Цикл с условием | `ПОКА a < 10 ДЕЛАТЬ ... КОН_ПОКА;` или `ПОКА a ≠ b НЦ ... КЦ` |
| Цикл со счётчиком | `ДЛЯ i ОТ 1 ДО 10 ШАГ 1 ДЕЛАТЬ ... КОН_ДЛЯ;` |
| Ввод / вывод | `ВВОД a;` / `ВЫВОД "a = ", a;` |
| Логика | `И`, `ИЛИ`, `НЕ`, `≠` |
| Функции | `sqrt(x)`, `корень(x)`, `abs(x)`, `sin(x)`, `cos(x)`, `min(a, b)` |
| Комментарий | `\| текст до конца строки` |

Инструкции могут разделяться точкой с запятой, но в новом синтаксисе
точка с запятой необязательна. Конец цикла со счётчиком включается
в диапазон.

Для квадратного корня основной формой считается `корень(x)`;
`квкорень(x)`, `корквадр(x)` и `sqrt(x)` — равноправные псевдонимы.

Таблицы индексируются с 1, как в учебнике: `A[1]` — первый элемент.
Поддерживаются одномерные и многомерные таблицы; границы могут быть
выражениями, например `A[1:N]`.

### Алгоритм с аргументами и результатами

```text
АЛГ решение квадратного уравнения (вещ а, b, с, х1, х2, лит y)
АРГ a, b, с
РЕЗ x1, х2, y
НАЧ
    ВЕЩ D
    D = b*b - 4*a*c
    ЕСЛИ D < 0 ТО
        y := "нет решения"
    ИНАЧЕ
        y := "есть решение"
        x1 := (-b + sqrt(D)) / (2*a)
        x2 := (-b - sqrt(D)) / (2*a)
    ВСЕ
КОН.
```

Такой алгоритм превращается в Python-функцию. Имя с пробелами заменяется
на имя с подчёркиваниями, поэтому вызвать его можно из следующей ячейки:

```text
АЛГ Вызов
НАЧ
    ВЫВОД решение_квадратного_уравнения(1, -5, 6);
КОН.
```

Кириллические и латинские буквы, выглядящие одинаково (`а`/`a`, `с`/`c`,
`х`/`x`, `у`/`y`), считаются одной и той же буквой в именах переменных.
