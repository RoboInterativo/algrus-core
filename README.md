# algrus-core

АлгРус — алгоритмический язык русской нотации. Пакет содержит лексер,
парсер, генератор Python-кода и ядро для Jupyter.

## Установка

```bash
python -m venv venv
source venv/bin/activate
pip install -e .

# регистрация ядра в Jupyter
python install.py
```

После установки перезапустите Jupyter и выберите ядро **«АлгРус»**.

### Подсветка синтаксиса и кнопки символов

В `extentions/algrus-symbols` лежит готовое расширение JupyterLab 4:
подсветка АлгРуса и кнопки `≠`, `≤`, `≥`, `:=`, `«»`, `^` на панели
инструментов блокнота.

```bash
pip install --no-deps ./extentions/algrus-symbols
```

Пересобрать расширение после правок в `extentions-src/algrus-symbols`:

```bash
cd extentions-src/algrus-symbols
./build.sh
pip install --force-reinstall --no-deps ../../extentions/algrus-symbols
```

После установки перезапустите JupyterLab целиком (не только ядро) и
обновите страницу в браузере.

## Использование из Python

```python
from algrus_core import Lexer, Parser, PythonCodeGenerator

source = """
АЛГ Пример
НАЧ
ЦЕЛ а, б, сумма;
а := 2;
б := 3;
сумма := а + б;
ВЫВОД "Сумма: ", сумма;
КОН.
"""

ast = Parser(Lexer(source)).parse()
python_code = PythonCodeGenerator().generate(ast)
print(python_code)
```

## Синтаксис

| Конструкция | Пример |
| --- | --- |
| Программа | `АЛГ Имя НАЧ ... КОН.` |
| Заголовок алгоритма | `АЛГ Имя (ВЕЩ a, b, ЛИТ s) АРГ a, b РЕЗ s НАЧ ... КОН.` |
| Объявление | `ЦЕЛ a, b;` / `НАТ n;` / `ВЕЩ x;` / `ЛОГ flag;` / `СИМВ s;` / `ЛИТ s;` |
| Таблицы | `ЦЕЛ таб A[1:100]` / `ВЕЩ таб B[1:10, 1:10]` |
| Элемент таблицы | `A[i] := 5` / `B[2, 3] := 1.5` |
| Присваивание | `a := 10;` или `a = 10` |
| Степень | `x^2`, `2^3^2` |
| Строки | `"текст"`, `«текст»`, `„текст"` |
| Условие | `ЕСЛИ a > b ТО ... ИНАЧЕ ... ВСЕ;` |
| Цикл с условием | `ПОКА a < 10 ДЕЛАТЬ ... КОН_ПОКА;` или `ПОКА a ≠ b НЦ ... КЦ` |
| Цикл со счётчиком | `ДЛЯ i ОТ 1 ДО 10 ШАГ 1 ДЕЛАТЬ ... КОН_ДЛЯ;` или `нц для i ОТ 1 ДО n ... кц` |
| Ввод / вывод | `ВВОД a;` / `ВЫВОД "a = ", a;` / `нс` — перевод строки |
| Функция с типом результата | `АЛГ цел фибоначчи(цел n) ... знач := ... КОН` — значение возвращается через `знач` |
| Логика | `И`, `ИЛИ`, `НЕ`, `≠` |
| Функции | `sqrt(x)`, `корень(x)`, `abs(x)`, `sin(x)`, `cos(x)`, `min(a, b)` |
| Комментарий | `\| текст до конца строки` |

Инструкции могут разделяться точкой с запятой, но в новом синтаксисе
точка с запятой необязательна. Конец цикла со счётчиком включается
в диапазон.

### Функции, возвращающие значение

Заголовок `АЛГ <тип> <имя>(<параметры>)` объявляет функцию. Результат
присваивается служебной переменной `знач` (как в КуМире) и возвращается
из функции:

```algrus
АЛГ цел фибоначчи (цел n)
НАЧ
  ЕСЛИ n ≤ 2 ТО
    знач := 1
  ИНАЧЕ
    знач := фибоначчи(n-1) + фибоначчи(n-2)
  ВСЕ
КОН

АЛГ вызов
НАЧ
  ЦЕЛ i
  нц для i ОТ 1 ДО 20
    ВЫВОД фибоначчи(i), " "
  кц
  ВЫВОД нс
КОН
```

Для квадратного корня основной формой считается `корень(x)`;
`квкорень(x)`, `корквадр(x)` и `sqrt(x)` — равноправные псевдонимы.

Таблицы индексируются с 1, как в учебнике: `A[1]` — первый элемент.
Поддерживаются одномерные и многомерные таблицы; границы могут быть
выражениями, например `A[1:N]`.

### Алгоритм с аргументами и результатами

```text
АЛГ решение квадратного уравнения (вещ а, b, с, х1, х2, лит y)
АРГ a, b, с
РЕЗ x1, х2, y
НАЧ
    ВЕЩ D
    D = b*b - 4*a*c
    ЕСЛИ D < 0 ТО
        y := "нет решения"
    ИНАЧЕ
        y := "есть решение"
        x1 := (-b + sqrt(D)) / (2*a)
        x2 := (-b - sqrt(D)) / (2*a)
    ВСЕ
КОН.
```

Такой алгоритм превращается в Python-функцию. Имя с пробелами заменяется
на имя с подчёркиваниями, поэтому вызвать его можно из следующей ячейки:

```text
АЛГ Вызов
НАЧ
    ВЫВОД решение_квадратного_уравнения(1, -5, 6);
КОН.
```

Кириллические и латинские буквы, выглядящие одинаково (`а`/`a`, `с`/`c`,
`х`/`x`, `у`/`y`), считаются одной и той же буквой в именах переменных.


## Робот и лабиринт

В ячейке Jupyter доступны команды исполнителя «Робот»:

| Команда | Что делает |
| --- | --- |
| `карта("...", "...")` | задаёт стены; `0` — свободно, `1` — стена, `2` — выход |
| `вперед()` | шаг в направлении взгляда |
| `влево()`, `вправо()` | поворот на 90° |
| `закрасить()` | закрасить текущую клетку |
| `залить()` / `залей()` | закрасить всю доступную область |
| `найти_выход()` / `выйти()` | провести робота к выходу `2` по кратчайшему пути |
| `впереди_свободно()`, `справа_свободно()`, `слева_свободно()` | датчики стен |
| `на_выходе()` | робот стоит в клетке выхода `2` |
| `сброс()` | вернуть робота в `(0, 0)` |

Робот стартует в левом верхнем углу `(0, 0)` и смотрит вверх.
Выход из лабиринта можно найти правилом правой руки:

```text
АЛГ ВыходИзЛабиринта
НАЧ
  ЦЕЛ шаги;
  шаги := 0;
  карта(
    "0011111",
    "1010001",
    "1011101",
    "1000001",
    "1111101",
    "1000021",
    "1111111"
  );
  ПОКА не на_выходе() и шаги < 500
  НЦ
    ЕСЛИ справа_свободно()
    ТО
      вправо();
      вперед();
    ИНАЧЕ
      ЕСЛИ впереди_свободно()
      ТО
        вперед();
      ИНАЧЕ
        влево();
      ВСЕ
    ВСЕ
    шаги := шаги + 1;
  КЦ
КОН.
```

Правило правой руки работает для лабиринтов без замкнутых островков.
Если выход не отмечен цифрой `2`, `на_выходе()` всегда возвращает `ЛОЖЬ`,
поэтому в примере есть ограничение по числу шагов.

Если нужен гарантированный путь для любого лабиринта, можно вызвать
встроенный поиск в ширину:

```text
АЛГ ВыходПоКратчайшему
НАЧ
  карта(
    "0011111",
    "1010001",
    "1011101",
    "1000001",
    "1111101",
    "1000021",
    "1111111"
  );
  найти_выход();
КОН.
```

`найти_выход()` сам поворачивает робота и ведёт его по кратчайшему пути
к клетке `2`. Синоним — `выйти()`.
