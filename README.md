## Синтаксис

| Конструкция | Пример |
| --- | --- |
| Программа | `АЛГ Имя НАЧ ... КОН.` |
| Заголовок с результатами | `АЛГ Имя (ВЕЩ a, b, ЛИТ s) АРГ a, b РЕЗ s НАЧ ... КОН.` |
| Объявление | `ЦЕЛ a, b;` / `НАТ n;` / `ВЕЩ x;` / `ЛОГ flag;` / `СИМВ s;` / `ЛИТ s;` |
| Таблицы | `ЦЕЛ таб A[1:100]` / `ВЕЩ таб B[1:10, 1:10]` |
| Элемент таблицы | `A[i] := 5` / `B[2, 3] := 1.5` |
| Присваивание | `a := 10;` или `a = 10` |
| Степень | `x^2`, `2^3^2` (правая ассоциативность) |
| Строки | `"текст"`, `«текст»`, `„текст"` (все три варианта) |
| Условие | `ЕСЛИ a > b ТО ... ИНАЧЕ ... ВСЕ;` |
| Цикл с условием | `ПОКА a < 10 ДЕЛАТЬ ... КОН_ПОКА;` или `ПОКА a ≠ b НЦ ... КЦ` |
| Цикл со счётчиком | `ДЛЯ i ОТ 1 ДО 10 ШАГ 1 ДЕЛАТЬ ... КОН_ДЛЯ;` или `нц для i ОТ 1 ДО n ... кц` |
| Ввод / вывод | `ВВОД a;` / `ВЫВОД "a = ", a;` / `нс` — перевод строки |
| Функция с типом | `АЛГ цел фибоначчи(цел n) ... знач := ... КОН` |
| Логика | `И`, `ИЛИ`, `НЕ`, `≠`, `≤`, `≥`, `<>` |
| Арифметика | `+`, `-`, `*`, `/`, `div`, `mod` |
| Функции | `sqrt(x)`, `корень(x)`, `abs(x)`, `sin(x)`, `cos(x)`, `min(a, b)`, `max(a, b)`, `sign(x)`, `ln(x)`, `lg(x)` |
| Строковые функции | `длин(s)`, `позиция(sub, s)`, `юникод(c)`, `юнисимвол(n)` |
| Комментарий | `\| текст до конца строки` |

Точка с запятой необязательна (можно разделять операторы переносом строки).
Конец цикла со счётчиком включается в диапазон.

### Функции, возвращающие значение

Заголовок `АЛГ <тип> <имя>(<параметры>)` объявляет функцию.
Результат присваивается служебной переменной `знач` (как в КуМире)
и возвращается из функции:

```algrus
АЛГ цел фибоначчи (цел n)
НАЧ
  ЕСЛИ n ≤ 2 ТО
    знач := 1
  ИНАЧЕ
    знач := фибоначчи(n-1) + фибоначчи(n-2)
  ВСЕ
КОН

АЛГ вызов
НАЧ
  ЦЕЛ i
  нц для i ОТ 1 ДО 20
    ВЫВОД фибоначчи(i), " "
  кц
  ВЫВОД нс
КОН
```

`корень(x)` — основная форма; `квкорень(x)`, `корквадр(x)` и `sqrt(x)` — псевдонимы.

Таблицы индексируются с 1: `A[1]` — первый элемент. Границы могут быть
выражениями: `A[1:N]`.

### Алгоритм с аргументами и результатами

```text
АЛГ решение квадратного уравнения (ВЕЩ a, b, c, x1, x2, ЛИТ y)
АРГ a, b, c
РЕЗ x1, x2, y
НАЧ
  ВЕЩ D
  D := b*b - 4*a*c
  ЕСЛИ D < 0 ТО
    y := "нет решения"
  ИНАЧЕ
    y := "есть решение"
    x1 := (-b + sqrt(D)) / (2*a)
    x2 := (-b - sqrt(D)) / (2*a)
  ВСЕ
КОН.
```

Такой алгоритм превращается в Python-функцию. Имя с пробелами заменяется
на имя с подчёркиваниями:

```text
АЛГ Вызов
НАЧ
  ВЫВОД решение_квадратного_уравнения(1, -5, 6);
КОН.
```

Кириллические и латинские буквы, выглядящие одинаково (`а`/`a`, `с`/`c`,
`х`/`x`, `у`/`y`), считаются одной и той же буквой в именах переменных.

## Робот и лабиринт

В ячейке Jupyter доступны команды исполнителя «Робот»:

| Команда | Что делает |
| --- | --- |
| `карта("...", "...")` | задаёт стены; `0` — свободно, `1` — стена, `2` — выход |
| `вперед()` | шаг в направлении взгляда |
| `влево()`, `вправо()` | поворот на 90° |
| `закрасить()` | закрасить текущую клетку |
| `залить()` / `залей()` | закрасить всю доступную область |
| `найти_выход()` / `выйти()` | BFS: кратчайший путь к клетке `2` |
| `впереди_свободно()`, `справа_свободно()`, `слева_свободно()` | датчики стен |
| `на_выходе()` | робот стоит в клетке выхода `2` |
| `сброс()` | вернуть робота в `(0, 0)` |

Робот стартует в левом верхнем углу `(0, 0)` и смотрит вверх.

### Обход правилом правой руки

```text
АЛГ ВыходИзЛабиринта
НАЧ
  ЦЕЛ шаги;
  шаги := 0;
  карта(
    "0011111",
    "1010001",
    "1011101",
    "1000001",
    "1111101",
    "1000021",
    "1111111"
  );
  ПОКА не на_выходе() и шаги < 500
  НЦ
    ЕСЛИ справа_свободно()
    ТО
      вправо();
      вперед();
    ИНАЧЕ
      ЕСЛИ впереди_свободно()
      ТО
        вперед();
      ИНАЧЕ
        влево();
      ВСЕ
    ВСЕ
    шаги := шаги + 1;
  КЦ
КОН.
```

Правило правой руки работает для лабиринтов без замкнутых островков.
Если выход не отмечен цифрой `2`, `на_выходе()` всегда возвращает `ЛОЖЬ`,
поэтому в примере есть ограничение по числу шагов.

### Гарантированный путь (BFS)

```text
АЛГ ВыходПоКратчайшему
НАЧ
  карта(
    "0011111",
    "1010001",
    "1011101",
    "1000001",
    "1111101",
    "1000021",
    "1111111"
  );
  найти_выход();
КОН.
```

`найти_выход()` использует поиск в ширину (BFS), сам поворачивает робота
и ведёт его по кратчайшему пути к клетке `2`. Синоним — `выйти()`.

## Пересборка расширения JupyterLab

Расширение собирается один раз и кладётся в основной Python-пакет.
При `pip install algrus-core` оно уже включено.

Если вы правите `index.js` / `algrus-mode.js`, пересоберите:

```bash
cd extensions-src/algrus-symbols
./build.sh
```

`build.sh` копирует результат в `algrus_core/labextension/`.

```bash
pip install --force-reinstall --no-deps .
```
